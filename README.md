# Carreadi

Upload your CV, get matched to live jobs, see what you already have and what's missing,
and follow a step-by-step plan to close the gap.

Live at https://carreadi.naijabukana.com

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run typecheck
```
